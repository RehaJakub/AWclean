## Výběr pro web

Pro sekci O nás doporučujeme společný boční pohled na dvě dodávky a snímek levého boku s čitelným polepem. Společný boční pohled byl po schválení uživatelem nasazen do sekce O AWCLEAN místo fotografie střechy. Web používá WebP a responzivní velikosti; JPG originál zůstal zachovaný. Ostatní fotografie zatím nejsou připojené do UI.

Rozložení O AWCLEAN respektuje poměr fotografie 4:3: na počítači je snímek širší vedle fotografie čištění, na mobilu přes celou šířku nad fotografií práce a milníky.
